# 多人海龟汤（暂名）

用 Go 开发实时房间服务，先完成真人主持的「共探模式」，再逐步增加竞答模式、AI 主持、Vue 网页端与 Flutter App。

## 当前阶段

目前只有最小的 HTTP 服务和健康检查接口。它用来确认 Go 工程可以启动，还不能创建房间或玩游戏。

## 已确定的规则

- 房主和主持人是不同身份；房主、出题人或其他用户都可以申请担任主持人。
- 真人主持只能回答「是」「否」「无关」。
- 玩家可以私下提交还原，由主持人判定；其他人只看到正确、错误或不完整的判定。
- 玩家申请查看汤底并获批准后，转为旁观者，不能再以玩家身份参与同一局。
- 任何看过汤底的人，都不能以玩家身份参与同一局。
- 共探模式允许开始后加入；答对者转为旁观者，其他玩家继续。
- 竞答模式开始后不允许加入；轮流限时提问，第一位还原正确者获胜。
- 独探模式需要 AI 主持，安排在真人主持玩法稳定之后。

## 第一版目标

用户能够注册、创建共探房间、通过房间码加入、选择题目、由真人主持回答，并在断线重连后继续查看本局问答。首版采用单个 Go 服务；游戏规则在服务端执行，客户端只展示状态和提交操作。

## 运行

安装 Go 依赖后，在本目录执行：

```sh
go run ./cmd/server
```

访问 `http://localhost:18080/health`，预期返回 `{"status":"ok"}`。

## 代码位置

- `cmd/server/main.go`：程序入口，创建 Gin 路由并启动 HTTP 服务。
