# 网页界面设计

当前网页的静态稿按模块保存：

- [游戏首页、账号、题目社区与个人页](game/index.html)
- [房间与单人模式](play/gallery.html)
- [管理后台](admin/index.html)

首页汇集功能入口。游戏和后台内部页面只显示返回当前流程的按钮；按钮、表单、确认弹窗与手机布局均有独立静态图。静态稿中的题目、账号和性能数字是排版示例，不代表线上数据。

## 画图素材

使用内置 ImageGen 生成两张完整 UI 概念图，再用 HTML/CSS 制作可读的逐页静态稿，中文文字与操作控件都由页面绘制。

- [首页概念图](references/home-concept.png)：以旧 H4 插画为画风参考，生成没有顶栏和侧栏的雨夜侦探咖啡馆首页；三张有独立插画和票券按钮的入口分别通向多人房间、单人模式、题目社区，账号与发布入口嵌入场景。
- [共探房间概念图](references/room-concept.png)：以上述首页为画风参考，生成只含返回按钮的房间内页；细化房间信息、成员、汤面、提问记录、提问、还原和申请看答案的卡片与操作状态。

局部证物插画及其 ImageGen 提示词分别记录在 [游戏设计说明](game/README.md) 和 [玩法设计说明](play/README.md)。
