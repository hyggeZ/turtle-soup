# 第 595 条 核心路径覆盖率

在隔离 PostgreSQL 16 上串行运行账号、社区、房间、单人 AI 四个包的测试。Go 覆盖率统计已执行的语句，路径权限和并发结果由对应断言核对。

| 测量范围 | 语句覆盖率 |
| --- | ---: |
| 账号包自身测试 | 57.1% |
| 社区包自身测试 | 76.8% |
| 房间包自身测试 | 77.5% |
| 单人 AI 包自身测试 | 83.9% |
| 四包合计，各包只采集自身 | 77.7% |
| 四包合计，采集其他包调用 | 79.7% |

| 场景 | 已有验收 |
| --- | --- |
| 带会话的跨站写操作 | 不同来源拒绝、本地与可信代理场景通过。 |
| 题目评论与剧透 | 玩家席位下限制未授权评论及汤底；覆盖与加入房间的竞争。 |
| 真人房间身份与重连 | 退出登录或禁用账号后在线连接被清除；覆盖掉线、事件重放与读取失败。 |
| 单人对局、额度与重放 | 验证对象归属、并发开局上限，以及超时释放操作和同一操作结果重放。 |

账号包当前以内存夹具验证登录，跨包覆盖也没有执行 `PGStore.CreateUser`、`FindUser`、`CreateSession`、`DeleteSession`。这些方法另有全站浏览器回归，未计入本表。第 671 条以真实账号路径补测会话 Cookie。两组百分比来自同一组测试和不同采集范围，2.0 个百分点的差值代表观测差异。

```powershell
go test -p=1 -count=1 -covermode=count '-coverprofile=coverage.out' ./internal/account ./internal/forum ./internal/room ./internal/agent
go test -p=1 -count=1 -covermode=count '-coverpkg=./internal/account,./internal/forum,./internal/room,./internal/agent' '-coverprofile=cross.out' ./internal/account ./internal/forum ./internal/room ./internal/agent
go tool cover '-func=cross.out'
```

运行前设置独立的 `TEST_DATABASE_URL`。没有新增线上代码路径或负载，本次不记录 RPS 差值。
