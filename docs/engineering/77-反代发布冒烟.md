# 第 765 条 反代发布冒烟

网页能打开、数据库连接正常时，API 仍可能被反代错误转发。发布在原有进程、数据库就绪和首页检查之后，经同一个 Nginx 回环地址读取两条业务路径。公开 `/api/soups` 需要 200 JSON，匿名访问 `/api/admin/users` 需要 401 JSON。只核对状态和内容类型，响应体丢弃。探测禁用本地 curl 默认配置且不走外部代理，无需账号或会话。

| 模拟反代响应 | 原版 | 新版 |
| --- | --- | --- |
| 公开 200 JSON，匿名后台 401 JSON | 通过 | 通过 |
| 公开接口意外返回 200 HTML | 通过 | 回滚 |
| 公开接口返回 503 JSON | 通过 | 回滚 |
| 匿名后台意外返回 200 JSON | 通过 | 回滚 |

WSL 共复验 8 项既有发布与就绪场景。新增三种故障中，直接就绪与首页各成功 20 次，新版仍等待受限重试结束后回退，旧二进制哈希一致。公开检查失败时同轮跳过后台检查。每个 HTTP 探测仍有 3 秒预算。

夹具复跑使用本地 `.local/release-672-fixture.sh smoke-baseline` 与 `candidate`。模拟运行用时约 3.04、10.36 秒，场景数与重试路径不同。候选多两次只读探测，业务请求运行路径无新增动作。上述计时为本地夹具耗时。
