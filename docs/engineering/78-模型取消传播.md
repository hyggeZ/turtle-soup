# 第 767 条 模型取消传播

新增独立回归，验证调用方主动取消能传到正在等待的上游模型。用真实本机 HTTP 模型夹具和 Docker PostgreSQL。夹具先确认已收到模型请求，再取消 Go 入口请求的 Context。模型客户端的 8 秒超时只作为后备，测试要求上游在 2 秒内收到取消。

| 三轮独立测试 | 模型客户端触发超时 | 调用方主动取消 |
| --- | ---: | ---: |
| 应用返回 503 的整次处理耗时 | 276–295 ms | 26–199 ms |
| 每轮故障时保存的判定事件 | 0 | 0 |
| 每轮故障时保存的上游尝试 | 1 | 1 |
| 随后重试并重放的判定事件 | 1 | 1 |
| 每轮实际模型调用总数 | 2 | 2 |

两组共 6/6 通过。新增路径三轮均触发上游取消，两次低于测量时钟分辨率，一次约 0.55 ms。已实际发出的上游请求继续计入尝试和额度。取消后操作锁被释放，重试沿用同一个操作 ID，成功后重放不再调用模型。主动取消相对客户端超时的整次耗时由触发方式决定，用于验收故障处理。生产业务路径不增加调用或计时步骤。
