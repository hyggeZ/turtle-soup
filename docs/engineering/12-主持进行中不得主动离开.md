# 主持期间阻止主动离开

## 规则与问题

真人主持在对局进行中不能主动退出。旧页面虽然会弹出“离开当前对局？”确认框，但点击“确认离开”就返回大厅并卸载房间页；WebSocket 随之断开，服务端会暂停对局。暂停状态下页面还会解除主持标记，主持人也能直接返回大厅。这与主持应留在本局的规则不一致。

现在进行中和暂停中的主持人尝试返回时，只显示“主持期间不能离开”的提示，不执行页面跳转，不清除房间恢复记录。对局结束后可以正常返回。主持人意外断线或关闭浏览器时，服务端仍暂停对局；重连后仍按原规则恢复。

## 实现与验证

- 房间页把 `active` 和 `paused` 状态下的主持身份都上报给页面入口；页面入口统一拦截主动跳转。
- 提示框使用一个“知道了”按钮；通用确认框继续支持原有双按钮操作，单按钮时也能正确取得焦点。
- `npm run build` 通过。此改动只改变前端导航，未增加服务端请求或数据库语句；旧路径可确认离开，新路径不可确认离开。没有声称性能提升。

浏览器或操作系统强制关闭页面无法由前端阻止，恢复依赖既有的断线暂停与重连机制。
