# 第 605 条 AI 评测样例去重

评测题集原有校验能拦住重复 ID。同一个故事、问题和历史换个新 ID 仍会计作额外样例，还可能给完全相同的输入配上互相矛盾的标签。开发集、边界集、留出集加载时都检查内容唯一性。

判重时沿用故事去空白规则，比较任务类型、去掉首尾空白的输入和原顺序的完整历史。遇到重复或标签冲突会指出两条样例 ID，由维护者决定如何修正。有效样例的原文、顺序和指纹保持一致。

| 验收 | 变更前 | 变更后 |
| --- | --- | --- |
| 同输入相同标签，使用不同 ID | 接收 25 条 | 拒绝并说明内容重复 |
| 同输入不同标签，使用不同 ID | 接收 25 条 | 拒绝并说明标签冲突 |
| 正常题集 | 开发 144、边界 36、留出 24 | 数量与指纹一致 |

Windows amd64 单机交替运行五轮，每组 128 次加载。耗时为中位数，内存是每次加载的分配量。

| 题集 | 加载耗时，旧→新 | 内存，旧→新 |
| --- | ---: | ---: |
| 开发 | 265.0→344.9 µs | 116,544→155,115 B |
| 边界 | 66.6→80.5 µs | 29,304→38,214 B |
| 留出 | 544.9→636.0 µs | 160,736→208,394 B |

校验需要保存已见输入及其标签，少量有历史的样例需要编码历史。各组的耗时波动有重叠，分配量增幅稳定。留出集的中位增量约 91 µs。开销只在离线题集加载时发生，保留校验以防重复或冲突扭曲评测。加载与验证期间模型调用数为 0。
