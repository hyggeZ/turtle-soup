# 第 276 条 AI 长局证据检索评测

单人 AI 主持会保留近期问答，在命中代号或短语时补入较早的原文。离线评测复用第 165 条的两份合成长局，每局 50 轮。14 个样例由人工标注早期相关轮次，其中 7 个需要历史窗口以外的证据，共标注 10 轮。

- 精确率等于选中的相关旧问答数除以选中的全部旧问答数。结果为空时精确率无定义。
- 召回率等于选中的相关旧问答数除以跨样例标注的相关旧问答总数。
- 无证据场景误取率按无需旧证据却选入至少一条旧问答的样例比例计算。

原文按时间顺序送给模型。测试验证近期部分保持原顺序，将新增的早期问答按出现次数和人工标注核对，重复提问也按各自出现次数计数。这里测量选入证据的命中比例。 [Ragas Context Precision 的排名定义](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_precision/)

14 项全部通过，其中包括重复问题次数、否定记录和近期重命名。历史 JSON 增加 822 字节，约 3.14%。漏掉的是无引号的早期代号「帆桨」。套件保留这条已知缺口，并允许后续补齐；所有选入的早期证据仍须符合人工标注。评测在本地调用现有编码与检索函数，比较的是提供给模型的证据和历史字节。
