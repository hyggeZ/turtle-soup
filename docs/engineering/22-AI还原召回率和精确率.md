# 第 055 条 AI 还原召回率和精确率

原有评测报告有错误通关率。这个比例衡量把错误或不完整的还原放行了多少，单看它会漏掉把正确还原拒绝的问题。新报告增加 `restorePass`，把人工标为正确的数量、模型判为正确的数量和实际命中数量一起写入。

- **召回率**用命中数除以人工正确数。正确样例超时、无响应或返回格式错误时，照样计入应通过的分母。
- **精确率**用命中数除以模型判为正确的数量。模型从未判出正确时，报告为 `null`。
- 分母为零表示指标不适用。已有错误通关率保留原口径，仍只在拿到有效判定的非正确还原上计算。

## 回归和开销

测试覆盖正确命中、正确样例超时、不完整被误放行、没有预测为正确、没有样例。评测包和 `cmd/ai-eval` 的测试通过。用已有的两份 `qwen-plus` 结果复算。相同的历史 108 条评测集中有 104 条还原，其中人工正确 22 条，两个历史提示词版本均判对这 22 条，召回率和精确率都是 22／22。新字段让分母可核对。这组历史数据未用于比较两个提示词的其他能力。

| 固定假模型，144 条样例生成一份报告 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 5 轮耗时中位数，每轮 2,000 份 | 17,373 ns/op | 16,770 ns/op |
| 五轮耗时范围 | 15,863–19,636 ns/op | 14,595–21,545 ns/op |
| 单份报告分配 | 28,816–28,819 B，35 次 | 28,832–28,835 B，37 次 |

两组耗时范围交叠，不能据此称速度提升。两个可空比例给每份报告增加约 16 B 和两次分配，此开销发生在离线评测。保留新指标，以便今后用同一题集比较漏判与误放行。本次复算使用已有输出，未重复调用付费模型。
