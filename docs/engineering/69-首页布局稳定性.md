# 第 642 条 首页布局稳定性

首页先显示默认入口，身份接口返回后才显示「我的主页」或「管理后台」。原布局会随着按钮文案变宽而移动。账号入口现在预留文案、内边距和图标所需宽度。桌面后台入口出现在发布按钮上方，窄屏仍沿用原有排列。

同一台 Windows 机器使用 Chromium，三轮交替加载新旧生产构建，共 36 个样本。1440×900 和 390×844 分别测访客、玩家、超级管理员。图片响应统一延后 150 ms，先让首屏绘制，再释放身份接口响应。使用浏览器 Layout Instability API，按最大会话窗口统计无用户输入的位移。[Chrome CLS 测量说明](https://web.dev/articles/cls)

| 身份与视口 | 原 CLS → 新 CLS | 账号入口移动 | 发布按钮移动 |
| --- | ---: | ---: | ---: |
| 桌面超级管理员 | 0.002864 → 0 | 21.14 → 0 px | 169.39 → 0 px |
| 桌面玩家 | 0.000094 → 0 | 21.14 → 0 px | 0 px |
| 窄屏玩家或超级管理员 | 0.000236 → 0 | 13.80 → 0 px | 0 px |
| 两端访客 | 0 → 0 | 0 px | 0 px |

候选 18 个样本均未观测到两个入口移动。两版图片加载窗口均无观测偏移，图片请求数一致。CSS 原始产物 95,991→96,224 B，增加 233 B，JS 原始体积为 215,457 B。以上为身份接口延迟的实验室结果。

同一套 Playwright 专项旧版通过 1/5，新版通过 5/5。测试覆盖 320、390、921、1440 像素视口，核对访客、玩家和管理员的入口，确认按钮互不遮挡、键盘可达且可进入后台。Vue 的 24 项测试、类型检查和生产构建均通过。
