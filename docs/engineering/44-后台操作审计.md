# 第 288 条 后台操作审计

超级管理员可以从后台打开「操作审计」，查看操作时间、操作者、动作及账号或题目 ID。列表按审计 ID 倒序读取，每页最多 50 条。HTTP 响应带 `Cache-Control: no-store`。日志与请求耗时各有独立记录。

- 新建账号、修改密码、停用和启用账号、隐藏与恢复题目时，业务写入与审计写入在 PostgreSQL 的同一个事务中提交。密码、摘要、汤面和汤底都不入审计表。
- 一次请求同时改密与停用时记录两条动作，合在一个 SQL 写入。重复提交且状态相同时沿用现状。重复隐藏若实际清理了遗留等待房，会记录本次操作。
- 后台账号无权执行的改动不产生成功记录。审计写入被拒绝时，创建、密码和旧会话、题目公开状态与等待房状态均回滚，房间通知也在事务成功后才发送。

## 验收

- 两项写入验收与两项迁移验收各跑 3 轮，共 12 次通过。覆盖新库、旧库升级、6 种动作、重复请求、权限拒绝和审计失败回滚。
- 游标接口独立跑 3 轮。每轮插入 52 条，读取第一页后再插入一条。第二页仍只含最早的两条，续页结束。三类非授权调用和错误游标均被拒绝。
- 完整 Chromium 游戏流程连续两轮通过，用例耗时 14.0 和 14.2 秒。超级管理员隐藏一条题目后能在网页看见对应审计记录，普通用户的审计请求返回 403。独立的审计页面检查覆盖 1,440、890、320 像素视口、翻页、键盘焦点和状态提示。

Vue 测试 24 项通过，前端产物增加 4,500 字节 JavaScript 与 1,984 字节 CSS。

## 写入成本

基线 `d327408` 和候选交替运行 3 对。每轮先预热每类接口 4 次，再测 20 次，每一版、每类动作共 60 个请求。运行环境是 Windows Gin 测试进程和经本地 SSH 转发的隔离 PostgreSQL 16。表中时间是各轮统计值的中位数，SQL 次数由 pgx 追踪获得，包含事务语句。题目测试交替隐藏和恢复，不涉及批量关闭房间。

| 写入接口 | SQL 次数 基线 / 候选 | P50 基线 / 候选 | P95 基线 / 候选 |
| --- | ---: | ---: | ---: |
| 创建账号 | 2 / 5 | 108.90 / 161.84 ms | 124.31 / 201.57 ms |
| 停用或启用账号 | 6 / 7 | 98.81 / 116.91 ms | 120.17 / 141.04 ms |
| 隐藏或恢复题目 | 7.5 / 8.5 | 129.96 / 153.72 ms | 172.31 / 196.72 ms |

创建账号新增显式事务的开始、审计写入和提交。已有事务的操作增加一次写入。创建账号还包含原有的 bcrypt，SSH 往返也计入各接口耗时。
