# 第 707 条 PostgreSQL 语句统计

应用追踪能数出请求发起了几次数据库操作。临时 PostgreSQL 加载 `pg_stat_statements` 后，还能看到每种语句的调用数、数据库端执行时间和缓冲区访问。采集按当前测试库、测试角色及顶层语句过滤，从每批正式请求前后的累计值计算差值。报告只留语句种类、归一化指纹和统计值，不发出 SQL 原文或参数。全程未重置共享计数。[PostgreSQL 16 扩展说明](https://www.postgresql.org/docs/16/pgstatstatements.html)

测试使用 PostgreSQL 16.15、扩展 1.10 和真实 Go 房间路由。每批 16 局，每局 6 次 HTTP 操作，覆盖快照、提问、同操作 ID 重放及主持回复。两种并发各重复三次，正式请求总计 576 次。

| 每批结果，中位数 | 1 路并发 | 4 路并发 |
| --- | ---: | ---: |
| 顶层语句调用数 | 720 | 720 |
| 语句指纹数 | 18 | 18 |
| PostgreSQL 总执行时间 | 26.59 ms | 38.31 ms |
| PostgreSQL 缓冲区命中数 | 2,833 | 3,195 |
| HTTP 批次用时 | 14.12 s | 3.71 s |
| HTTP P95 | 230.41 ms | 324.85 ms |

六批共享块读取与临时块读取均为零。这是同一夹具的热缓存结果。数据库执行时间不包括连接池、SSH 隧道、HTTP、应用处理和编码。之前的回放已有请求耗时与结果一致性，新增的是每批 18 种归一化语句以及服务器侧执行数据。以上用于定位耗时层级，当前数据不足以归因于 Go CPU 热点或建议新增索引。[合成房间流量回放](53-合成房间流量回放.md)

复跑使用独立 PostgreSQL，启动时预加载扩展并在测试库创建视图，采样语句按当前库及角色过滤。测量用例位于本地 `.local/pg-stat-observe-707_test.go`，原始数据位于 `.local/measurements/707-room-replay-statements.txt`。
