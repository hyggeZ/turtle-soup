# 第 610 条 房间游标生成测试

真人房间同时保留旧查询和显式分页协议。新增 Go fuzz 只调用游标纯函数，用合成查询覆盖版本、方向、重复参数、数字范围和百分号编码。有效游标要满足方向及取值约定，重新编码后解析结果应一致。现有数据库集成测试另外核对分页、旧客户端和剧透过滤规则。[Go Fuzzing](https://go.dev/doc/security/fuzz/)

| 验收 | 变更前 | 变更后 |
| --- | ---: | ---: |
| 房间游标 fuzz 入口 | 0 | 1 |
| 固定种子 | 0 | 14 |
| 生成测试执行数 | 0 | 14,495 |
| 发现的新覆盖输入 | 0 | 21 |
| 原有历史分页集成测试 | 3 | 3/3 通过 |

本机 Go 运行 12 秒生成测试，两个 worker，无失败。前三个分页集成用例在隔离 PostgreSQL 通过，耗时约 11.10 秒，包含测试数据准备。生成测试只增加回归覆盖，产品请求路径无新增开销。

```powershell
go test ./internal/room -run '^$' -fuzz '^FuzzRoomEventRequest$' -fuzztime 12s -parallel 2
```
