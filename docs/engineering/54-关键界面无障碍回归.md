# 第 385 条 关键界面无障碍回归

密码字段的名称统一为「密码」。注册表单单独关联密码说明，说明包含服务端的 8–72 字节要求与密码复用提示。显式切换登录或注册后，焦点移到新表单的用户名字段，按 Tab 可继续到密码。[W3C 表单说明](https://www.w3.org/WAI/tutorials/forms/instructions/)

共用确认弹窗把说明关联到弹窗本身。打开剧透确认时，辅助技术可以获取「看过汤底后不能再以玩家身份参加该题」的后果。剧透确认先聚焦取消，Tab 和 Shift+Tab 在弹窗内循环，Esc 关闭后焦点返回触发按钮。取消不会申请查看汤底。[W3C 模态弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)

Chromium 回归检查实际 Vue 静态产物的无障碍树，覆盖登录字段、剧透确认和房间操作。检查结果反映浏览器暴露的语义以及键盘行为，语音播报体验需由具体屏幕阅读器另外验证。[Playwright 无障碍快照](https://playwright.dev/docs/aria-snapshots)

## 前后对照

使用同一套 Playwright 用例和同一台 Windows 机器上的 Edge Chromium。旧版构建固定为 `8c8b614`，两组均加载实际 Vue 生产构建，接口使用固定合成响应。旧版 5 项用例中通过 2 项，另外 3 项共有 5 个断言失败。候选连续三轮共 15/15 通过。

| 断言 | 旧版 | 候选 |
| --- | --- | --- |
| 注册密码字段精确名称、独立说明 | 0/2 | 2/2 |
| 进入注册和返回登录后聚焦用户名 | 0/2 | 2/2 |
| 剧透后果作为弹窗的可访问描述 | 0/1 | 1/1 |
| 剧透弹窗键盘循环与取消、房间 AX 控件 | 2/2 用例 | 2/2 用例 |

取消后没有查看汤底的 POST，主动确认会发一次并显示受控响应。登录和注册切换不发网络请求。两版静态 JavaScript 主包 213,288 → 213,515 B，增加 227 B，CSS 均为 95,991 B。测试用来验证语义和交互。

隔离 PostgreSQL 的常规 Chromium 套件跑两轮共 14/14 通过，涵盖 5 项专项测试、完整玩家与后台旅程和断线补查。Vue 24 项测试、类型检查和生产构建通过。

在 `web` 完成 `npm run build` 后，可在 `e2e` 执行 `npm exec playwright test accessibility.spec.js` 单独复测。常规浏览器验收自动执行这 5 项用例。
