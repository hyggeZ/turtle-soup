# 第 515 条 AI 多轮稳定性

一次评测答对 23 道题，另一次也答对 23 道，两次出错的题可以完全不同。`pass^k` 按题看每轮是否都命中人工标签，再除以题数。调用失败按该轮未命中统计。

```powershell
go run ./cmd/ai-eval stability 第一轮.json 第二轮.json
go test ./cmd/ai-eval -run 'TestStability'
go test ./cmd/ai-eval -run '^$' -bench BenchmarkStabilityReports -benchmem -cpu 1 -benchtime 250ms -count 5
```

命令要求每一轮是从当前冻结题集生成的全量报告。检查范围、指纹、模型、提示词版本及逐例 ID 和标签，输出每轮正确数、调用失败数以及总体、问答和还原的全对比例。同一路径重复提交会被拒绝。采样是否独立由运行者负责，复制文件也会改变路径。

| 合成报告验收 | 原有单轮或两版汇总 | 多轮全对统计 |
| --- | --- | --- |
| 留出集 24 条，两轮分别错在不同位置 | 两轮均 23/24，95.83% | 22/24，91.67%，问答与还原各 11/12 |
| 第二轮全部调用失败 | 第二轮无有效判定 | 保留 24 次失败，全对 0/24 |

Windows amd64、Go 1.26.5、单 CPU，每组 5 次基准。读盘、题集核对、聚合与 JSON 输出的中位耗时为两轮 1.053 ms、207,023 B/op，五轮 1.427 ms、246,442 B/op。以上是离线工具开销，模型请求均为 0 次。`cmd/ai-eval` 全包测试在只包含本次改动的隔离源码上通过，三套题集和不兼容报告都有回归。数据来自合成报告，可用实际独立采样报告替换输入。
