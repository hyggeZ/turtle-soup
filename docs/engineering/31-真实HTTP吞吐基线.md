# 第 149 条 真实 HTTP 吞吐基线

新增按需运行的 `TestReadHTTPThroughput`。测试起一套真实回环 HTTP 服务，复用生产 Gin 路由、中间件、会话与 PostgreSQL 查询。服务使用临时数据库和日志目录，连接池固定为 16。HTTP 传输保留连接复用，预热与正式采样分开。

| 场景 | 固定数据 |
| --- | --- |
| 匿名公开题目列表 | 500 条合成题目，首屏有 20 条结果 |
| 长局主持快照 | 已回答问答 5,000 对、4 项待办，主持会话读取空事件增量和待办 |

每个场景测 1、4、16 并发，每个组合重复 3 轮，每轮预热 `并发数 × 5` 次，正式完成 600 次。正式计时从并发发车到该批响应体读取完成。成功 QPS 以成功数除以该批耗时，延迟分位只使用成功请求，按最近秩计算。日志同时记录 HTTP 状态码、错误类型、错误率和数据库连接池等待。

## 实测结果

在 `mine` 的一次性数据库运行。Linux amd64、Xeon Platinum 8255C、4 个逻辑 CPU、约 3.64 GiB 内存，Go 1.26.5、PostgreSQL 16.15。应用与 PostgreSQL 同机，保留业务请求的结构化日志和数据库追踪。表中每项取三轮的中位数。

| 场景 | 并发 | 成功 QPS | P50（ms） | P95（ms） | P99（ms） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 公开题目 | 1 | 1,140.18 | 0.86 | 1.02 | 1.29 |
| 公开题目 | 4 | 2,548.91 | 1.39 | 2.53 | 3.42 |
| 公开题目 | 16 | 2,970.78 | 4.68 | 9.90 | 12.37 |
| 长局主持快照 | 1 | 228.94 | 4.32 | 4.64 | 5.33 |
| 长局主持快照 | 4 | 498.84 | 7.80 | 9.99 | 11.68 |
| 长局主持快照 | 16 | 510.65 | 31.01 | 42.33 | 48.34 |

10,800 次正式请求全部返回 HTTP 200，连接池空闲连接等待与取消计数均为 0。主持快照从 4 并发升至 16 并发，成功 QPS 仅增加约 2.4%，P95 升至约 4.2 倍。这个拐点可用于后续复测查询和序列化开销。结果只覆盖两个读场景的固定回环负载。
