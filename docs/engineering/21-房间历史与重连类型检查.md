# 第 053 条房间历史与重连类型检查

房间历史和重连会在 Vue 页面、实时通知、分页及断线补查之间共用数字游标和时间。第 053 条先在 `eventHistory.js` 和 `retryTiming.js` 试行 TypeScript 检查。JSDoc 定义事件 ID、增量页、布尔状态和毫秒数。合并事件按数字 ID 排序并保留调用方附带的字段。

`npm run build` 先跑 `npm run typecheck`，再由 Vite 构建。TypeScript 使用 `checkJs` 和 `noEmit` 检查两份 JavaScript，不生成线上代码。服务器返回值的运行时校验继续由现有逻辑执行。 [TypeScript checkJs](https://www.typescriptlang.org/tsconfig/checkJs.html) · [TypeScript noEmit](https://www.typescriptlang.org/tsconfig/noEmit.html)

## 验收和开销

在隔离文件中把数字事件排序故意改成字符比较，类型检查以 TS2339 阻止构建。正常文件通过检查，前端 14 项功能测试和完整构建均通过。

| 同机连续三轮 | 改动前 | 改动后 |
| --- | ---: | ---: |
| Vite 构建耗时 | 1877、1921、1812 ms | 2280、1914、2000 ms |
| 类型检查耗时 | 无 | 1164、952、1017 ms |
| 发布的 JS／CSS 字节数 | 205,048／93,213 B | 205,048／93,213 B |

发布的 JS 和 CSS 两版 SHA-256 一致。收益是在构建时发现类型错误，代价是本机多约 1.02 秒类型检查。三轮 Vite 计时存在波动，未将差异归因于改动。此阶段的类型检查只覆盖上述两个模块。
