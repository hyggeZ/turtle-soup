# 技术词典逐项评估

依据用户提供的《技术词典_频率排行.md》原序，结合项目当前 Go/Gin、PostgreSQL、Vue、WebSocket 和百炼 Qwen 的实际功能，对全部 802 个词条逐项判断。原词典位于项目外，评估文件保留了词条名称和编号。

| 序号 | 评估 |
| --- | --- |
| 001–100 | [逐项记录](001-100.md) |
| 101–250 | [逐项记录](101-250.md) |
| 251–500 | [逐项记录](251-500.md) |
| 501–802 | [逐项记录](501-802.md) |

**已有**表示代码中存在对应能力；**候选/可加入/改良**表示有合理实验位置，尚不能当成已实现；**暂不/不适用/需证据**表示当前任务边界或收益不足。重复词条可以共用一次实验，但仍保留原编号。四份文件合计 802 项，编号连续且无重复。

实施时先固定基线，再逐项核对前置条件。候选独立实现、回归和对照测量，验收后留下该项报告并提交。结果未达到预期的候选也保留数据和决定。

当前[上线回归与性能基线](../18-上线回归与性能基线.md)已固定。按原序复核到第 086 条，各项测试结果和采用决定见[工程记录](../README.md)。
