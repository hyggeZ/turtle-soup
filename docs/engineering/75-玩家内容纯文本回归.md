# 第 756 条 玩家内容纯文本回归

题目、评论和房间记录来自用户输入。实际 Vue 生产构建需将这些内容按文本显示。浏览器测试使用带引号、与号和无执行能力的标签形文本，检查玩家能看到原文，且页面不会创建对应元素。

| 界面 | 专项断言 |
| --- | ---: |
| 社区列表和题目详情的标题、汤面 | 4 个位置 |
| 普通评论、已展开剧透评论、获准查看的汤底 | 3 个位置 |
| 房间内的公开问答记录 | 1 个位置 |

三项测试每轮执行 8 个原文断言和 8 个节点检查。另核对访客、取消查看、受到拒绝和获准查看四种路径。访客与取消均不发出揭底请求，拒绝后仍隐藏汤底。允许查看时，前端继续沿用原来的请求和权限规则。

专项覆盖从 0 增加到 8 个位置。Chromium 连跑三轮共 9/9 通过，约 19.2 秒。此次添加浏览器回归，前端业务代码和生产构建产物沿用原版。

```powershell
cd web
npm run build
cd ../e2e
npm exec playwright test plain-text.spec.js
```
