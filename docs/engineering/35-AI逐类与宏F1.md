# 第 209 条 AI 逐类与宏 F1

`ai-eval` 把问答的「是、否、无关」和还原的「正确、不完整、错误」分别统计。每类输出人工标注数、有效预测数、正确预测数和 F1。两组各有一个宏 F1。

- 单类 F1 为 `2 × 正确预测数 ÷ (人工标注数 + 有效预测数)`。超时、无效 JSON 等失败仍计入人工标注数，因此会计为对应类别的漏判。
- 同一类的人工作答数与预测数都为零时，该类 F1 为 `null`。宏 F1 对有定义的类别等权平均，全部缺失时也为 `null`。
- `compare` 先验证题集指纹和逐例标签，再从逐例结果重算指标。新老报告都能输出逐类差值、宏 F1 差值、模型与提示词版本。现有错误通关、漏掉正确还原等质量门槛继续在同一次对照中检查。

```powershell
go run ./cmd/ai-eval compare baseline.json candidate.json
```

使用第 135 条保存的两份 `qwen-plus` 报告。两份均为同一 24 条人工标注题集，每类各 4 条，比较过程只读取归档的逐例判定。

| 判定 | 人工样本数 | v2 F1 | v3 F1 | 差值 |

| **问答宏 F1** | **12** | **0.915344** | **1.000000** | **+0.084656** |

| 指标 | 原版 | 增加 F1 |

| 耗时中位数 | 4.818 µs/份 | 5.964 µs/份 |
