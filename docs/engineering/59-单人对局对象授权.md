# 第 453 条 单人对局对象授权

单人对局由服务端按登录账号和对局 ID 一起校验。已有真实 PostgreSQL 测试覆盖其他账号无法读取对局。本次补上两个操作方向的防御回归：提问和主动查看汤底。

测试用两个隔离账号经正常 HTTP 路由操作。其他账号请求被拒绝时，响应里没有汤底，原对局的状态、动作占用、事件和尝试记录不变化，双方额度和模型调用数也不增加。继续由所属账号走正常流程，验证权限约束不妨碍参与者操作。

隔离 PostgreSQL 16 上连续三轮通过，新增直接操作覆盖由 0 项增至 2 项。每种操作均为 3/3 返回 `404`，模型调用、事件、额度、揭底记录和尝试记录的增量都为 0。局主随后使用同一操作 ID 成功揭底，重试仍幂等。新增子用例单轮耗时约 0.34–0.35 秒，包含快照读取与状态断言。此条只增加回归覆盖。

```powershell
go test -v ./internal/agent -run '^TestSoloGameWithPostgres$' -count=3
```
