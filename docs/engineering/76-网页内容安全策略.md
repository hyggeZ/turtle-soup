# 第 764 条 网页内容安全策略

Nginx 在 `/index.html` 返回 CSP。首页、后台和直接请求入口文档均包含这份策略。脚本、样式、图片和连接来源限制为同源，禁止对象嵌入、文档基地址和外部页面嵌入该页面。入口仍发送 `no-cache`，带内容哈希的资源继续走长期缓存。[CSP 规范](https://www.w3.org/TR/CSP3/) · [Nginx 响应头规则](https://nginx.org/en/docs/http/ngx_http_headers_module.html)

浏览器独立对照使用实际 Vue 构建、回环 HTTP 和真实同源 WebSocket。原版和候选都收到 1 条房间问答，首页、后台日志仪表和时间线正常。普通应用场景观测到的策略违规为 0。一条独立的无害测试样式由原版应用，在候选上被阻止并记录 1 次样式策略事件。同源外部样式保持生效。

全站浏览器旅程让隔离 Vite 预览从部署配置读取原样策略，并通过 HTTP 返回。Go API、房间 WebSocket 和数据库使用真实隔离连接。8 个主流程步骤通过，实际页面响应 11/11 带有策略，未记录到违规。Nginx 1.27.3 容器另测了两个配置版本。三条文档路径原先没有 CSP，候选均返回策略。两个内容哈希资源保持长期缓存，缺失资源保持 404。测试分别核对了浏览器行为和配置装载，生产响应时延未实测。
