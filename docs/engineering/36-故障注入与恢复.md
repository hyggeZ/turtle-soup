# 第 237 条 故障注入与恢复

测试主动切断一条依赖路径，再恢复依赖并重发原操作。验收同时检查接口响应、数据库记录和玩家可见内容，覆盖多人房间掉线、房间数据库连接异常和 AI 上游超时。

| 场景 | 注入方式 | 恢复后核对 |
| --- | --- | --- |
| 房间 WebSocket 断连 | 由既有房间集成测试主动关闭主持人的实际 WebSocket 连接 | 房间暂停，主持人认证重连后恢复。玩家能按事件游标回看，私有内容仍按权限过滤 |
| 房间 PostgreSQL 连接失败 | 清空应用连接池的已有连接，并阻断该池的新拨号。测试断言使用独立连接 | 断开期间读写均返回 500，落库数为零。恢复后用同一操作号重试并重放，最终只有 1 条提问和 1 条操作记录，玩家快照无汤底 |
| Qwen HTTP 超时 | 本地模拟上游先读取请求，再将响应头阻塞至实际 250 ms HTTP 超时 | 接口返回 503 并释放处理租约。复用同一操作号重试返回 200，之后重放不再请求上游。最终只有 1 条游戏事件、2 次实际模型调用与相应配额计数 |

## 验证结果

使用 PostgreSQL 16.15 的一次性数据库。Go 测试各重复 5 次，三组共 15 次全部通过，完成后清理测试库。耗时按本次样本范围记录。

| 指标 | 5 次样本范围 |
| --- | ---: |
| 房间正常读快照 | 7.31–7.81 ms |
| 房间断线读 / 写返回 500 | 0.079–0.118 / 0.033–0.325 ms |
| 房间恢复拨号后第一次提交 | 7.79–9.52 ms |
| 房间恢复后的幂等重放 | 0.86–1.12 ms |
| Qwen 超时返回 503 | 256–259 ms |
| 假上游恢复后第一次重试 | 3–4 ms |
| AI 幂等重放 | 小于 1 ms，计时按整毫秒输出 |
| 房间 WebSocket 完整集成用例（含数据准备和其余断言） | 0.30–0.41 s |

本项增加自动验收，业务请求路径和重试算法沿用现有实现。数据库故障是连接拨号被当场拒绝，Qwen 恢复时间来自本地模拟上游。表中的耗时适用于复测这些场景。

```powershell
$env:TEST_DATABASE_URL = 'postgres://用户:密码@127.0.0.1:5432/独立测试库?sslmode=disable'
go test -count=5 -v ./internal/agent -run '^TestQwenTimeoutRecoveryWithPostgres$'
go test -count=5 -v ./internal/room -run '^(TestRoomPostgresConnectionRecovery|TestAnswerRevealAndRoomJoin)$'
```
