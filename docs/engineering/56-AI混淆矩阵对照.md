# 第 402 条 AI 混淆矩阵对照

问答和还原报告已有分类矩阵。过去 `ai-eval compare` 显示逐类 F1 和质量门槛，分数相同的两个模型仍可能把样本判到不同的错误类别。

比较命令在校验题集指纹和逐例身份后，按已验证的逐例结果重算两版的问答、还原矩阵，并输出候选减基线的差值。行是人工标签，列是模型标签。正数表示该流向变多，负数表示变少。调用失败继续计入错误数和 F1 的人工支持数。旧报告缺少汇总字段也可以比较。

```powershell
go run ./cmd/ai-eval compare baseline.json candidate.json
```

用同一 24 条合成判定做前后对照，固定旧版为 `790578e`。两份报告均为 20 条正确、1 条调用失败、问答宏 F1 0.75。旧命令无法输出矩阵字段，候选识别到问答 6 个非零差值。还原矩阵的差值都是 0，失败的一条未被当作模型预测。测试覆盖旧汇总缺失和输入汇总被改写的情况。

Windows/amd64 上交替三对，每版共 192 次。计时包括读入两份报告、校验、重算和输出，全程离线。各轮中位数从 1.034 ms 到 1.007 ms，P95 中位数从 3.984 ms 到 4.040 ms，两组波动重叠。输出 JSON 从 3,322 B 增至 5,123 B。AI 评测和 Agent Go 包回归通过。
