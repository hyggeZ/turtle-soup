# 第 421 条 链路首个失败阶段

后台链路详情先给出该请求首个记录到的失败阶段，再保留完整时间线。失败阶段按服务端保存的阶段完成记录顺序选择。对 AI 判定来说，模型调用失败通常先写入 `ai.model`，外层 `ai.decision` 随后结束。这个顺序在旧日志缺少阶段起点时也能使用。

发生内部失败后如果业务最终返回成功，已记录的失败仍可查看。HTTP 返回错误但没有阶段失败标记时，详情显示「本次请求未记录失败阶段。」定位以当时已记录的阶段为依据，可以结合时间线继续排查。

同一套 4 项 Chromium 用例加载两版实际 Vue 产物，后台接口使用固定合成链路。旧版仅 1/4 通过，另外 3 项有 5 处预期断言失败。候选连续三轮 12/12 通过，覆盖模型子阶段优先、缺起点的旧日志、未标记的 404 和正常请求。前端类型检查与构建通过，入口 JavaScript 增加 415 B。阶段选择在浏览器中完成，复用链路响应。
